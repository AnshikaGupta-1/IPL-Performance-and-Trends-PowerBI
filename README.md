# Project Overview

This dashboard transforms raw IPL match data into an interactive Business Intelligence solution for exploring tournament performance from multiple perspectives.

The report consists of two analytical pages:

### 📊 Page 1 – Tournament Insights

- Season-wise filtering
- IPL Title Winners
- Orange Cap & Purple Cap statistics
- Batting performance analysis
- Bowling performance analysis
- Venue-wise match results
- Toss decision analysis
- Match result distribution

### 📈 Page 2 – Team Performance

- Team-wise batting analysis
- Team-wise bowling analysis
- Top 10 batsmen
- Top 10 bowlers
- Interactive team selection
- Dynamic KPI updates
